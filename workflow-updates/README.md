# Workflows de Arquinovatos

Canal de plantillas para Comfy launcher. Los alumnos pulsan **Actualizar
workflows**; no necesitan Git ni configurar una dirección de descarga.

Los paquetes tienen versión propia y se verifican antes de usarse. Las
colecciones anteriores y **Mis workflows** se conservan. El launcher adapta
las plantillas compatibles con los modelos y nodos ya instalados; no descarga
modelos ni instala nodos al actualizar workflows. El paquete íntegro permanece
guardado, incluidas las plantillas que requieren componentes adicionales.

El índice del canal está firmado. Cada ZIP se enlaza mediante un commit
inmutable, su tamaño y su SHA256. Las fuentes y documentación de las
plantillas figuran en el archivo de procedencia de cada publicación.

Este canal distribuye workflows JSON. No incluye modelos, instaladores,
claves, sesiones, datos de alumnos ni el código privado del launcher.

Las referencias de los autores originales se conservan; esta publicación
no cambia las licencias de las obras originales ni de sus modelos.
